Capstone Project

May 2026

Description

This end-to-end data analysis project predicts music genres across a 50,000-record Spotify dataset using label-specific data imputation, feature extraction, and fine-tuned classification models including neural networks, random forests, and gradient boosting.

Key Features

This project demonstrates a comprehensive data pipeline, training predictive classifiers using messy, real world data. Technologies used include but are not limited to Python, Matplotlib, Pandas, Scikit-Learn, Numpy, and CSV.

  • Engineered an end-to-end multi-class classification pipeline to predict music genres across a 50,000-record Spotify dataset using fine-tuned Multi-Layer Perceptron, Random Forest, and Gradient Boosting models
  • Implemented domain-specific data imputation by grouping features by target class and replacing corrupted/missing values with localized medians to preserve data integrity and eliminate class imbalance
  • Executed dimensionality reduction using Principal Component Analysis to mitigate severe feature multicollinearity

Online Chatroom

Apr 2026

Description

This full-stack web application serves as an online chatroom that allows multiple users to chat across different browsers, using Python, FLask, Jinja, REST API, HTML, CSS, and JavaScript.

Key Features

This project demonstrates a modern full-stack web application architecture.

  • Built a full-stack asynchronous web application featuring a multi-browser chatroom powered by Flask and a custom JavaScript short-polling architecture that syncs message data dynamically every second
  • Designed a robust REST API pipeline using JSON payloads for secure authentication on both client and server side
  • Implemented real-time visual and interactive enhancements, including a stateful cookie-based session manager, a specialized server-side chat command parser, and a dynamic client-side theme switcher via DOM manipulation

Miyazaki Hayao: The Living Legend of Anime

Nov 2025

Description

This is a multi-page academic website that explores the life, beliefs, and cinematic themes of animator Miyazaki Hayao. The site is divided into three key areas: The World of Miyazaki Hayao, Beliefs Behind the Scenes, and A Mix of Real and Fantasy. The design uses semantic articles and sections to present cited research and includes an interactive quiz element on each page to engage users with the material.

Key Features

This project demonstrates compliance with modern responsive design and JavaScript interactions.

  • Responsive Layout: each page is built using CSS grid layout and employs media queries to optimize the structure for mobile device, tablet, and desktop viewports
  • JavaScript Interactivity: the site uses DOM queries to update page content, change CSS property, and provide interactive navigation menu using SVG
